## Oct 16,2026 
The conditionals prototyping assignment challenged me in learning how to break down visual ideas into functional code. I kept running into a roadblock when I had an idea of what I wanted to make but didn't know how to execute it. Slowly, I learned how to organize variables into different objects, play around with different calculations and make interactive drawings. 

For prototype one, I experimented with using variables mouseX and mouseY to control the movement of several "lasers". I used the mouse variables to both synchronize them and create lasers that moved in a perpendicularly. 
For prototype two, I used the mouse variables to control fill functions. I also experimented with using the mouse variable to control the amount of glow for the windows. It didn't give me the exact effect I wanted but it was interesting to try. 
For prototype three, I created a rocket that launches at an angle using the angleMode and rotation function. I also learned how to have multiple functions that are tethered to the variables of a single object. I also experimented with creating speed and acceleration variables to modulate the movement of the rocket. 

For my future prototypes I want to learn more about how to use sin and cos functions to make my movements more dynamic.
